With lime, success drifts toward teal #2DD4BF so “in stock” never reads as the accent.
  • Vibe: energy, voltage, “live wire”. Nothing else in e-commerce looks like this — it owns the word Voltra.
  • On dark graphite it pops hard — the card grid reads as a product wall with real character.
  • Trade-off: shares a green family with stock/status colors → we push success toward teal (done above).
  • Risk: love-it-or-hate-it. Lime demands restraint everywhere else — which Volt Dark already provides.

Blue keeps classic green/amber/red — statuses stay textbook and instantly readable.
  • Vibe: trust, clarity, “serious hardware store”. The safe, familiar choice for commerce.
  • Status colors pop cleanly — green/amber/red sit far from blue, zero palette collisions.
  • Trade-off: reads “another tech blue” — Stripe, Linear, Paystack, half the SaaS world live here.
  • Risk: on graphite it can feel corporate rather than electric; brand distinctiveness is weaker.
My call: volt-lime. Voltra is a brand built on the word voltage — lime-on-graphite makes that literal and it’s nearly unused in commerce, so the site is recognizable before the logo is read. Blue is the safe default, but safe is what the old cream-paper prototype already was. The only real cost of lime (status-color collision) is already solved above by shifting success to teal. If it feels like too much, electric blue is a one-line swap in the token file — the design doesn’t change anywhere else.
